# Subagent 报告接收端即时守门（通用方法论）

主 skill 把 subagent 报告用作决策**之前**，核对是否"真的做事了、做透了、证据连得上"。与派发端的 prompt 硬化（工具调用下限、已读清单等）配对使用：派发端规定 subagent 必须做什么，本 skill 验证是否做到。

## 辅助文件

- `references/dimensions.md` —— 五项核查的判定规则、常见降级模式、证据格式、示例 + 4 条通用高危盲区模板

执行核查时 Read `references/dimensions.md`，按其中每个维度逐项核对。本 SKILL.md 正文只保留骨架与判定要点。

## 核心原则

- **接收端验证**：主 skill 把 subagent 报告用于决策前的最后一道防线
- **默认阻断**：发现任一不一致即中止，由主进程三选一处理（见输出格式）
- **只读**：仅 Read 报告文本与派发 prompt，不修改任何文件
- **证据导向**：所有核查项都要求 subagent 提供可验证痕迹（调用次数、文件路径、具体差集数字、file:line 引用）

## 触发条件

主 skill 派发 subagent 执行以下任一类型任务后、在消费 subagent 结论前必须调用本 skill：

- 独立代码审查 / diff 对照 / 一致性核验
- 文档漂移检查 / 索引完整性枚举
- "找 X 类 bug / 查 Y 类遗漏"的证据搜集类任务
- 架构 / 模块边界核对

派发端应已在 prompt 里加入硬性要求（工具调用下限 N、已读清单、枚举而非抽样等）。本 skill 检查这些要求是否被满足。

## 输入契约

主调方须提供：

1. **subagent 的完整报告文本**（含结论段 + 已读清单段）
2. **主 skill 派发时的 prompt 硬性要求摘要**（工具调用下限 N、是否要求枚举闭环、是否要求差集数字等）
3. **本轮任务的"高危维度清单"**（可选）：主 skill 已知的易被 subagent 放过的盲区类型。未提供时按 `references/dimensions.md` 中的 4 条通用模板做兜底表态检查。

## 五项核查（概览）

详细判定规则、降级模式清单、证据格式、示例均在 `references/dimensions.md` 中展开。本节只列要点。

1. **工具调用计数**：`tool_uses < N` 阻断；`tool_uses = 0` 无条件阻断（空载回答）
2. **已读清单完整性**：需绝对路径、条数 < 3 阻断、清单缺失阻断
3. **枚举 vs 抽样降级**："无发现"必须附具体差集数字（`|A|=50, |B|=48, A−B = 2 条: [x, y]`）；仅定性陈述（"一致 / 无问题 / 未见明显错误"）直接阻断
4. **结论与证据连通**：每条结论必须引用 `file:line` 或 `file#section`；仅凭模型先验给出的抽象结论阻断
5. **跨 agent 盲区覆盖**：对主调方提供的高危维度清单，报告必须逐项明确表态（已检查 X 维度 + 结论 + 证据）；跳过维度而不声明阻断

## 输出格式

### 通过

```
✅ Subagent 守门通过

报告来源：[subagent 标识 / 报告文件路径]
工具调用：X 次（≥ 要求下限 Y）
已读清单：M 个文件
高危维度覆盖：N/N 项已表态

无一致性问题。主调方可消费该报告。
```

### 阻断

```
❌ Subagent 守门阻断 — 发现 N 处问题

1. **[核查项编号 + 问题类型]**：[定位 + 原因]
   - 证据：[报告原文摘录]
   - 判定：[触发了哪条核查规则]
   - 建议：[修正方向]

...

### 处理选项（由主进程决定）
- A) 主 skill 重派 subagent（可硬化 prompt / 调大 N / 明确要求枚举）
- B) 显式忽略该条继续（必须归档到项目忽略台账）
- C) 放弃使用该 subagent 结论，主 skill 亲自核查
```

## 阻断策略

**默认阻断**：无工具调用 / 已读清单 / 差集数字等客观证据即判不可采信。

## 记录落点（与 doc-sync-check / sync-check 共享）

主调方若选择"B 显式忽略继续"，必须将忽略项归档到项目约定的忽略台账：

```
[YYYY-MM-DD] [subagent-check] [任务名 / subagent 标识] [问题摘要] 理由：[用户陈述]
```

该台账供后续全量审计对账（已在相同位置落盘 doc / skill 快检忽略项的项目可复用同一份台账）。
